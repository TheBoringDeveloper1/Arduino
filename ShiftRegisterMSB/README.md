# Arduino | Shift register MSB
Uno sketch Arduino che tramite un registro a scorrimento 74HC595 fa accendere 8 led in sequenza MSB-First.

## Shift Register 74HC595
Il 74HC595 è un circuito integrato (IC) logico digitale che funge da registro a scorrimento (shift register) a 8 bit con ingresso seriale e uscita parallela (SIPO - Serial In, Parallel Out), dotato di un registro di memorizzazione (latch) e uscite a tre stati (tri-state). Viene comunemente impiegato nei progetti con microcontrollori (come Arduino o ESP32) per espandere il numero di pin di uscita digitali disponibili, utilizzando un numero ridotto di linee di controllo.

## Materiale utilizzato
* Scheda Arduino
* Shift register 74HC595
* Breadboard
* Cavi jumper
* Led
* Resistenze 220 ohm
